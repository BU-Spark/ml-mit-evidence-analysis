## Overview

_In this document, based on the available project outline and summary of the project pitch, to the best of your abilities, you will come up with the technical plan or goals for implementing the project such that it best meets the stakeholder requirements._

### A. Provide a solution in terms of human actions to confirm if the task is within the scope of automation through AI.

Analyze a number of images, and look for certain objects, such as cash, drugs, weapons, etc., or distinct appearances and emotions of people in the images that might help the human trafficking investigators to decide which images should be considered in their investigations.

### B. Problem Statement:

We will have to develop an image analysis model that would automatically process, analyze, and extract valuable metadata from image backgrounds for the purpose of helping human trafficking investigations. The system should be capable of performing several key tasks, including but not limited to object recognition, location identification, person characteristic analysis, etc.

### C. Checklist for project completion

1. Client kickoff: Data review + questions
2. Project Definition and Use Case Understanding
3. Research and Problem Understanding
4. Data Preparation and EDA
5. Implement Proof of Concept (PoC) AI/ML Model
6. Deployed PoC as a service
7. Evaluation
8. Final client presentation

### D. Outline a path to operationalization.

The Project can be used for identifying missing people and aiming to distinguish people with different appearance than the provided image. This would increase the success rate of identifying missing individuals and provide more instance help.
